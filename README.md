# FER202 Group 4 - Dormitory Management System (DMS)

> A modern, comprehensive web application for campus dormitory accommodation, room booking, utility billing, and maintenance management.

## 👥 Group & Course Information
- **Course:** FER202 - Front-End Web Development
- **Group:** Group 4
- **Project:** Dormitory Management System (DMS)

## 🚀 Tech Stack
- **Frontend Framework:** React 19 + TypeScript
- **Bundler & Build Tool:** Vite
- **Styling:** Tailwind CSS + Lucide React + Radix UI / ShadCN UI
- **Routing:** React Router DOM
- **Backend / Database Integration:** Supabase (PostgreSQL)

## 📦 Key Modules & Features
- 🏢 **Room & Bed Management:** Visual floor plans, bed allocation status (Available, Occupied, Maintenance, Reserved).
- 📝 **Registration & Accommodation:** Student dorm registration, contract lifecycle, and check-in/check-out workflow.
- ⚡ **Utility Billing:** Monthly electric and water meter recording, automated calculation, and invoice tracking.
- 🛠️ **Maintenance Requests:** Defect reporting with photo attachments, task assignment, and resolution logs.
- 📊 **Role-Based Portals:** Tailored workspaces for Students, Staff/Managers, and System Admins.
